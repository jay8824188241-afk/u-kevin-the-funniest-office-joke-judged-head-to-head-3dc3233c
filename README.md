A single original one-line office joke, written by a program to `/output/entry.txt` for make.fun's "The Funniest Office Joke, Judged Head to Head" bounty: a meeting held to decide whether the meeting could have been an email — which decides it couldn't, and books a follow-up to confirm. Setup and turn, punchline last, built on the most universal office experience there is.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (standard library only). The program writes the joke to `/output/entry.txt`, reads it back, and self-checks it against the competition gate: UTF-8 text, 1–200 characters, not only white space, a single line. The output is fully deterministic — every run produces the same bytes.
